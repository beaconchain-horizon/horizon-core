# Horizon Angel — Live Demo

این یک پیش‌نمایش زنده از قابلیت‌های Horizon Core است.

## 🔴 تغییر دامنه
فایل `config.js` را باز کنید و مقادیر `SWITCH_URL` و `BACKEND_URL` را به دامنه واقعی تغییر دهید.

## ساختار
- `index.html` — صفحه اصلی فروشگاه
- `dashboard.html` — داشبورد
- `sensors.html` — پنل سنسورها
- `blocks.html` — کاوشگر بلاک‌چین
- `license.html` — پنل مشتری
- `admin.html` — پنل ادمین

## Demo Mode
در حالت `DEMO_MODE: true`، همه داده‌ها شبیه‌سازی شده هستند.
