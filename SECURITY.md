# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Horizon Core, please report it privately.

**Do not open a public issue.**

Send details to: security@horizon-core.io

We will respond within 48 hours.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest  | ✅ Yes    |
| < latest| ❌ No     |
